# Edge-Cloud Collaboration with Large Foundation Models

## Background
Real-time perception systems are an essential component of intelligent Internet of Things (IoT) devices, such as industrial robots and household mobile devices. When performing basic perception tasks like semantic segmentation, the limited resources of edge platforms pose significant challenges. New environments bring new semantic classes, and small models on edge platforms can only segment limited information. 

Large foundation models, represented by the Segment Anything Model (SAM), are widely recognized for their superior generalization ability. This algorithm enables small models on edge platforms to achieve efficient, real-time IoT perception through an edge-cloud collaboration framework.

## Cloud-Edge Collaborative Inference Overview
Cloud-edge collaborative inference combines the processing capabilities of the cloud and edge devices to handle complex tasks more efficiently. 
* **The Cloud:** Deploys large-scale foundation models (like SAM) to handle complex, challenging samples using powerful computing resources.
* **The Edge:** Deploys small-scale models (like RFNet) to process simple samples in real-time, reducing latency and saving computational resources.

In this architecture, edge devices only transmit hard sample data to the cloud, greatly saving energy while maintaining high system accuracy.

## System Architecture and Workflow
The system continuously collects images at the edge and processes them efficiently while leveraging lifelong learning to adapt to dynamic environmental changes. 

The overall workflow of the system operates as follows:
1. Edge nodes collect samples for inference.
2. Edge nodes use the deployed Edge Model to infer these samples and obtain edge inference results.
3. The edge inference results are sent to the Hard Example Mining module.
4. The Hard Example Mining module classifies the samples, labeling them as "Hard" or "Easy" samples.
5. Easy samples are directly output with their edge inference results, while Hard samples are uploaded to the cloud node.
6. In the cloud inference module, hard samples are inferred by the SAM model to obtain the cloud inference mask, while class labels are obtained by the Edge Model.
7. The cloud inference results are generated by combining the cloud inference mask and the edge inference class results.
8. Edge nodes download the final cloud inference results, and the cloud node stores the hard samples in a replay buffer.
9. The cloud node performs lifelong learning training on the edge model based on the replay buffer samples.
10. The cloud node synchronizes the updated Edge Model back to the edge nodes.

## Core Components

### Segment Anything Model (SAM)
SAM is designed for promptable segmentation, capable of transferring its segmentation capabilities to new image distributions and tasks without extensive retraining (zero-shot transfer). Because SAM produces highly detailed segmentation masks but lacks class labels, its output is combined with the class-labeled results from the edge model.

### Hard Example Mining
The Hard Example Mining module determines whether a sample requires cloud intervention. Sending too many samples to the cloud increases latency, while sending too few decreases accuracy. 
Ianvs supports efficient mining approaches without relying on resource-heavy standalone classifiers:
* **Score Margin Based:** Computes the average score margin for each pixel. A larger margin indicates high confidence (Easy sample), while a smaller margin indicates low confidence (Hard sample).
* **AppealNet Based:** Utilizes a two-head architecture that builds a predictor head directly on top of the edge model's feature extractor to predict sample difficulty efficiently.
